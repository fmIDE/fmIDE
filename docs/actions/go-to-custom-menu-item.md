# Action `Go to Custom Menu Item`

Open Manage Custom Menus and prepare an item name; opening its menu and selecting the item remain manual.

## Description

Goes to the given Custom Menu Item.

1. Stores the custom_menu_item_name in the fmAutoMate Keyboard Buffer file.
2. Opens the `Manage Custom Menus` dialog

You must manually:

- select the Custom Menus view
- open the Custom Menu
- click in the list
- press the fmAutoMate keyboard shortcut to retype the name

## Full Syntax

