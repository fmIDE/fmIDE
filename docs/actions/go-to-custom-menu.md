# Action `Go to Custom Menu`

Open Manage Custom Menus and prepare the menu name in the fmAutoMate keyboard buffer; final selection is manual.

## Description

Goes to the given Custom Menu.

1. Stores the custom_menu_name in the fmAutoMate Keyboard Buffer file.
2. Opens the `Manage Custom Menus` dialog

You must manually:

- select the Custom Menus view
- click in the list
- press the fmAutoMate keyboard shortcut to retype the name
