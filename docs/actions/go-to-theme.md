## Description

Goes to the given theme.

1. Stores the theme name in the fmAutoMate Keyboard Buffer file.
2. Opens the `Manage Themes` dialog

You must manually:

- press the fmAutoMate keyboard shortcut to retype the name

## Full Syntax

