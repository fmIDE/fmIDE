# Action `Go to Table Occurrence`

Open Manage Database and prepare a table-occurrence name; select it manually in the Relationships graph.

## Description

Goes to the given table occurrence, if possible(*).

1. Stores the table occurrence name in the fmAutoMate Keyboard Buffer file.
2. Opens the `Manage Database` dialog

You must manually:

- switch to the Relationship view
- press the fmAutoMate keyboard shortcut to retype the name


## Full Syntax

```
[+].Go to Table Occurrence
```
