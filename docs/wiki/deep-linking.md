'Deep Linking' is the ability to link/jump to any thing in your FileMaker Development Environment.

# Shallow Linking

Some things in FileMaker are easy to get to - using native script steps.

For example, 

- we can jump to a layout (in browse mode) with a simple Go to Layout step.
- or we can open the script workspace with the Open Script Workspace step.

# Deep Linking

Other areas and elements are tucked away in dialogs, where normal FileMaker scripting no longer works.

These areas we refer to as deep GUI - and you need some technologies beyond native FleMaker scripting to get there.

fmIDE uses several techniques to reach the deep GUI - and different areas of the FileMaker IDE are more or less reachable.
