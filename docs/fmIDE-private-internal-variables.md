# fmIDE private internal variables ($fmide__[_]*)

In your fmIDE Action Scripts do not use variables starting with `$fmide__`!

fmIDE reserves fmide variables that have two or more underscores for internal use only.

The [public API variables](fmIDE-variables.md) with a single underscore are documented in the [fmIDE Variables](fmIDE-variables.md) page.

The rest of this page is thus for developers of fmIDE only.

- 2 underscores: [`$fmide__*` - private internal variables](#fmide-private-internal-variables-fmide___)
- 3 underscores:
  - [`$fmidess__*` - private variables for the fmIDE subscript system](#fmidess-private-variables-fmidess__)
  - [`$fmide___*` - private action-specific variables](#private-action-specific-variables-fmide___)

- [`$fmide___*` - private action-specific variables](#private-action-specific-variables-fmide___)
