/*/* _ColorImage ( pRGB_String )

Dynamically creates an image (file) with the given color which can be output via a container field (as a stored or unstored calculation) to produce dynamic color.

Set the following properties on the container field to get an edge to edge color:

• container: enlarge/reduce
• container: don't maintain proportions

and (to remove the border)

• field borders: ON
• field border width: 0px
• field border color: None

The current version of the function creates a 16x16 pixel gif file with the name "color«rrggbb».gif".


Parameters

pRGB_String - a string representation of a color using red green and blue values between 0 and 255 in any of the following formats:

  - red green blue or red ; green ; blue // as three separate numbers - with any separator
  - #RRGGBB or RRGGBB // as a 6 digit hexadecimal string - with or without a preceeding #
  - #RGB RGB // as a 3 digit hexadecimal string - with or without a preceeding #
  - JSON object with keys "red", "green" or "blue"

  - an empty parameter produces an empty result
  - any other value will be interpreted as a hex string, thus "1234567890" will be equivalent to "#567890"

Examples

_ColorImage ( "#524742" ) // Hexcolor with preceding "#"
_ColorImage ( "524742" ) // Hexcolor with no preceding "#"

_ColorImage ( "#c93" ) // Short (JavaScript) hexcolor - equivalent to #cc9933
_ColorImage ( "c93" ) // Short (JavaScript) hexcolor with no preceding "#" - equivalent to #cc9933

_ColorImage ( "82 ; 71 ; 66" ) // RGB decimal values separated by semicolon
_ColorImage ( "82¶71¶66" ) // RGB decimal values separated by white space

_ColorImage ( "{\"red\":82,\"green\":71,\"blue\":66}" ) // RGB decimal values as JSON
_ColorImage ( TextColor ( "#" ; RGB ( 82 ; 71 ; 66 ) ) ) // RGB passed via the color of a single (non-hex) charcater
