Set Error Capture [ ON ]
Allow User Abort [ OFF ]
If [ _IsFindMode ]
	Omit Record
Else If [ _IsKeySHIFT ]
	Show Omitted Only
Else If [ _IsKeyALT ]
	Perform Script [ "SYS Omit Multiple Records" ; Specified: From list ; Parameter: ]
Else
	Omit Record
End If
